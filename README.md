# Community Hub

This project is a simple Express + EJS site for the W01 Initial Site Creation assignment.

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open:
   http://localhost:3000

## Deployment

This project is prepared for Render deployment with a `render.yaml` file.

## Pages

- Home
- Organizations
- Projects
- Categories

## Notes

- All EJS pages use a shared header and footer partial.
- Static assets live in the `public` folder.
- `.env` is not included in the repository.
